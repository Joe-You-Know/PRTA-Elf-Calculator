## The new physically admitted joining rule

Source event `σ: N=op(A,B)` keeps its independent exact arithmetic certificate. An authored triangular contact grammar maps each distinct numerical value currently under examination to a primitive triangular face, with the actual incidence graph defined by sharing a **complete physical edge**. A contact witness for operand `A` and receiving output `N` is an ordered finite walk `f_A=e_0,e_1,...,e_k=f_N` in which every consecutive pair shares a verified vertex-pair edge. The complete source ID, input role, endpoints, all face IDs and exact shared edges are retained. All intermediate faces must be unoccupied by numerical source values. Distinct sources cannot share a relay face; distinct operand contacts must enter a single output face through different physical edges. **Relay faces carry contact provenance, not arithmetic data or a new numeric register value.**

Direct-edge transport is retained as the `k=1` special case. Placement and compound-route selection are constrained by actual physical contacts and audited. No arbitrary nonadjacent numerical producers are deemed lawful merely because their values are arithmetically equal.

**Purposeful nonconstruction:** If an optional relay contact is withheld, `expose_existing_contact` checks whether another physically witnessed route exists; if so it returns that unchanged source obligation with its complete replacement route receipt and a typed withheld-contact report. Withholding does not itself produce numerical blue, a numeric zero, a missing face or a new target. If an endpoint is withheld or no alternate route exists, the receiving contact is not claimed fulfilled. Exhausted search budgets are unresolved, not proofs of impossibility.

## Experiment

The same first two numerically valid distinct-value arithmetic producers from each of 1,000 publicly credited Kaggle Santa 2026 Elf Calculator puzzles (v0.3 comparison pool). Physical patch radius 3; every individual source-to-output contact route has at most 3 full-edge steps; bounded placement search 700 completed layouts after direct check.

- Numerically valid two-producer motifs: **993**; 7 puzzles insufficient.
- Original v0.3 strict direct-edge grammar admits **767** motifs.
- Multi-face source-contact transport admits **993/993**.
- **All 226 v0.3 rejections are recovered** by the new grammar: 207 direct-edge odd-contact cycles and 19 bounded direct-placement failures.
- All chosen transport routes are independently checked for actual edge receipts. Concrete positive example `scored_0005`: `411+176=587` then `587×411=241257`, with four operand-contact paths and each actual shared vertex-pair edge in the audit JSON.
- **24/24 unit tests passed**, eight new transport/withholding tests plus 16 inherited. Full census ~1.918 seconds one local run, not a stable performance metric.
- Public 1,000-program portfolio independently revalidated at **141,086 instructions**, SHA-256 `21d1d5245de5d41810e06ce6435df99059b2ba8a35f2bfcde3256e827675a5d7`.
- **No new score submission emitted, zero instruction savings claimed.** Contact admission is a physical feasibility finding, not yet an optimized arithmetic compiler result.

## Critical limits

1. The current small-motif mapping keys numerical **values**, not distinct occurrences bearing equal values. Full PCL source-occurrence indexing is the next step; the retained event-ID/role proof does not fully solve this distinction.
2. This is a **declared experimental multi-face contact grammar**, not a theorem that every arithmetic production can be physically transported or that PRTA requires this grammar.
3. It is **not** a full network of simultaneous contacts, and does not prove global face placement or lifelong port scheduling in the 48-register program.
4. Bounded search failures certify only lack of a located witness at that budget, not literal absence.
5. Next development: occurrence-indexed simultaneous routed contacts with lifetime and face-occupancy ledgers; integrate feasible family selection into actual whole-program arithmetic scheduling; measure genuinely shorter instructions and compare equal-budget non-geometric ablation.

An accurate abstract finding: **For this finite 993-motif test set, direct-edge contact restrictions can be relaxed to source-preserving routed contacts with complete physical edge receipts, without manufacturing numerical operands or replacing arithmetic verification.**
