**Completed bounded global rescheduling experiment, zero Kaggle score improvement.** This is a whole-program dependency scheduler of the **existing** source construction network, not yet a candidate-generating global multi-producer optimizer.

The code reads the full program, reconstructs occurrence identities and exact arithmetic source edges, prunes irrelevant ancestry, topologically reorders the full dependency DAG, attempts 48-register allocation, independently validates final source/target programs, and safely falls back to the original legal program when reallocation fails.
