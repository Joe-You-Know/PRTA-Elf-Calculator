# Adaptive triangular QR grammar v0.1 — new helper invention

Date: 2026-11-19. Experimental executable bundle available from current conversation: `prta_adaptive_grammar_v0_1.zip`.

**Purpose:** Start from existing target values and independently authored exact quotient–remainder relations, not the original sequence of helper constructions. Construct a finite triangular primitive face with three actually incident edge neighbors (each shares two source-labelled vertices), with source roles P,Q,R. Edge orientation is discrete; no numeric angle, Cartesian axis or wave calculation required. The author assigns the value-to-face grammar and verifies N=P Q+R. An exact-remainder-zero case withholds the R neighbor and retains a typed source closure report, not a literal number or arbitrary missing face.

The separate finite compiler proposes new helper values from exact target-relative arithmetic and positive-input QR relations. It checks whether one newly invented helper can support one or two remaining targets in fewer actual calculator instructions. No face or nonconstruction event is counted as arithmetic, and every proposed emitted program is independently validated.

**Positive constructed control:** starting values 2,3; targets 8,12. Reference sequence: 6=3+3;8=6+2;9=3*3;12=9+3, four instructions. Newly authored helper 4=2+2 supports 8=2*4 and 12=3*4: **three instructions**, all valid. The value 4 was not present in the reference source sequence. This demonstrates new-helper invention; it does not establish that triangular incidence is responsible for the saving.

**Full exact public benchmark:** 1,000 scored puzzles; 141,086 original instructions. Three suffix lengths 4,6,8, at most 50 target-derived candidate helpers per eligible cut, one new helper and up to two final target constructions. 2,189 eligible cuts; **0 improvements**. New total **141,086**, 1,000/1,000 independently valid, byte-identical SHA-256 `21d1d5245de5d41810e06ce6435df99059b2ba8a35f2bfcde3256e827675a5d7`. Eight unit tests pass. No Kaggle submission warranted.

**Boundaries:** Local triangular face-incidence construction is demonstrated, but this does not yet provide a full near-circular PRTA shell indexing, global joint reindexing across target families, or PRTA-specific performance evidence. The suffix-only search is strictly bounded and not an optimality certificate.

Keep unused candidate helpers genuinely unconstructed.
