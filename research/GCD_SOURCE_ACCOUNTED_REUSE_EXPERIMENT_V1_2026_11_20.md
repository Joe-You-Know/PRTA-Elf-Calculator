# Elf Calculator — source-accounted collective GCD reuse v1 (2026-11-20)

**Experiment outcome:** 0 accepted savings on independent verified 134,002-instruction bank in two bounded GCD-directed search families; positive **6→5** saving on a controlled original-source-sharing demonstration. 1000/1000 scored puzzles independently replayed for original, one-step rewrite output, and two-step output (all 134002, equal instructions). 2-page compiled LaTex/PDF. Artifact `prta_elf_source_accounted_gcd_reuse_v1.zip` SHA256 `22d9b4cf23944d7920abec1b9d5711b48257fe9fd113d1c260a6a7db1f02662d`; includes exact scripts, machine JSON, independent interpreter entry, TeX and PDF.

**Correctness / causal constraint:** Each original exact division `a=dq+r` has recorded remainder r=0. Collective `g=gcd(d1,...,dk)` yields factual `di=g*ei` but not a free constructed source occurrence `g`. Every rewrite must use values truly live before the instruction, including register overwritten semantics, exact integer operation legality, and strict reduced count after source-provenance pruning. Cost of constructing a missing factor g or intermediate ratio is included. No ECC assumptions.

**Scored data:** 3942 original prior/current denominator pairs with gcd>1; 3035 occur when that gcd numeric value is already live in a source register. 107 distinct conventional one-step quotient rewrite options were attempted, all fail strict instruction-saving test after canonical dead producer pruning. 471 potential two-step factor-construction cases, 595 explicit two-step register-SSA rewrites tested, no positive. Verified outputs of the scored search are completely unchanged relative to input. This does NOT establish absence of all better multi-target GCD transforms, nor that all possible GCD source carriers were exhaustively explored.

**Positive controlled construction:** Initial source registers (2,96,128), target (12,8). Source-unshared six-step example builds 4 then 8, obtains 12=96/8, builds *separately* another occurrence 4', then 16=4'*4' and 8=128/16. Source-shared program uses already-built 4 to produce both denominator8 and16, five steps. Independently interpreted both, count 6 vs 5. Standard arithmetic DAG source reuse can also discover this; it is NOT a newly discovered PRTA-specific saving nor claim of global shortest solution.

**Inference for PRTA indexing:** A shared factor g is relevant only if its source construction event and outgoing factor obligations are evidenced; scalar equalities / pairwise gcd provide candidate relationships, not evidence of common native original contact. Next test coordinated multi-output factor-ancestor restructuring with a conventional DAG optimizer as strict control, source-identity, liveness, overwritten registers and exact quotient/remainder certificates.
