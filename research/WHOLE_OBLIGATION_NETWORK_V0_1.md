# Whole-obligation multi-producer network v0.1 — matched comparison

2026-11-19. **Completed bounded prototype, no Kaggle score gain.**

User goal: optimize several shared helper families and their joining obligations together, not only each target independently. This experiment derives many prospective helper values from all target and resident-source exact quotient–remainder relationships; conducts a multi-depth beam search of shared source-event constructions; retains source-indexed arithmetic receipts, original targets already historically witnessed, three authored discrete edge roles, and safe nonconstruction reports. Every selected output is a legal scored `[op,i,j,d]` instruction. An absent event is never a numerical zero or a free target.

A deterministic source-relative one-based shell indexing uses `2s-1` whole triangular face slots at shell `s`, giving `s²` faces across shells 1..s. **This is an authored numerical contact representation and is NOT evidence of real physical PRTA face adjacency or global polygonal shell rotation.**

Visited-state reduction is 1,281 (about 4.76%). These are single-run times, not a reliable general speedup measurement. Both output CSVs are **byte-for-byte identical** to source, SHA-256 `21d1d5245de5d41810e06ce6435df99059b2ba8a35f2bfcde3256e827675a5d7`. No Kaggle submission warranted.

Positive control with starting (2,3), goals (8,12): independently invent helper 4=2+2 then 8=2*4 and 12=3*4; three instructions versus four-step reference. Six local tests passed, including undefined-source rejection, exact QR receipts, distinct structural edge roles and retention of every target.

**Scope boundary:** A broader three-cut configuration ran past the execution limit and produced no completed result. Despite deriving helper candidates from the whole target set, the completed scored experiment only rewrites terminal six-step windows and does not globally reschedule all helper families. Only free physical registers are used, and the beam restricts operand selection. Therefore zero gain cannot prove whole-network optimality, nor does it refute the wider PRTA proposal.
